GHOST HUNT
A Halloween-themed p5.js game built for the Hack Club Ghostship Workshop.

Avoid the enemy and chase the ghost.

How to Play:

Controls: Use your mouse to control your character/catcher across the screen.

Catch the ghost to collect it and increase your score.

Stay away from the Enemies! Touching them will end your game.

As time goes on, the difficulty increases.

Built With: p5.js - a JavaScript library for creative coding.

Designed for the Hack Club Ghostship workshop.

Available on itch.io: https://hanyamursaleen.itch.io/ghosthunt

OR: 
Clone or download this repository.

Open index.html in any web browser.

Alternatively, load the project files into the p5.js Web Editor and press Play.
