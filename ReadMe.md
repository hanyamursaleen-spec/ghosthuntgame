GHOST HUNT
A Halloween-themed p5.js game built for the Hack Club Ghostship Workshop.

Test your reflexes as you navigate a haunted arena to capture elusive ghosts while dodging dangerous enemies lurking in the dark!

🎮 How to Play

Controls: Use your mouse to control your character/catcher across the screen.

Objective: Move over the Ghosts 👻 to collect them and increase your score.

Avoid the Enemies: Stay away from the Enemies 👾! Touching them will end your game.

Survive: As time progresses, the difficulty ramps up—enemies move faster and appear more frequently!

🚀 Features

Halloween Aesthetic: Spooky themed visuals and playful mechanics.

Dynamic Difficulty: The game gets progressively harder over time as your score grows.

Simple & Intuitive: Easy mouse controls make it accessible for anyone to jump in and play.

🛠️ Built With

p5.js - JavaScript library for creative coding.

Designed for the Hack Club Ghostship initiative.

📦 How to Run Locally

Clone or download this repository.

Open index.html in any web browser.

Alternatively, load the project files into the p5.js Web Editor and press Play (▶).
